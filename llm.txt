  ```bash
  curl -s "https://sscc.birth1mark.workers.dev/validate?sscc=356012345600000016"
  ```

### 2.3 Expand a Sequential SSCC Range (Up to 500 Codes)
- **Endpoint**: `GET https://sscc.birth1mark.workers.dev/range?from={start}&to={end}`
- **Example**:
  ```bash
  curl -s "https://sscc.birth1mark.workers.dev/range?from=35601234560000001&to=35601234560000005"
  ```

### 2.4 Lookup GS1 Country Prefix
- **Endpoint**: `GET https://sscc.birth1mark.workers.dev/prefix?sscc={code}`

### 2.5 Extract & Validate SSCCs from EDIFACT, SAP IDoc, XML, or CSV Payload
- **Endpoint**: `POST https://sscc.birth1mark.workers.dev/extract`
- **Headers**: `Content-Type: text/plain` (or `application/json` with `{"content": "..."}`)
- **Max Payload**: 1 MB
- **Example**:
  ```bash
  curl -s -X POST "https://sscc.birth1mark.workers.dev/extract" \
    -H "Content-Type: text/plain" \
    -d "UNA:+.? 'UNB+UNOC:3+SENDER+RECEIVER+261123:0800+1'GIN+BJ+356012345600000016'"
  ```

## 4. GS1 SSCC-18 Technical Reference

### Structure of an SSCC (18 Digits + Optional 2-Digit AI `00`)
- **Application Identifier (AI)**: `00` (indicates a fixed-length 18-digit SSCC in GS1-128 barcodes, preceded by FNC1).
- **Digit 1 — Extension Digit (`0`–`9`)**: Used to increase capacity of the Serial Reference (e.g., `0` = Standard Pallet, `1` = Carton/Case, `3` = Mixed Pallet).
- **Digits 2 to N — GS1 Company Prefix (GCP)**: 6 to 11 digits assigned by a local GS1 Member Organization (first 3 digits indicate the GS1 Country Prefix, e.g., `560` = Portugal, `400`–`440` = Germany, `840`–`849` = Spain, `001`–`139` = USA).
- **Remaining Digits up to Digit 17 — Serial Reference**: Zero-padded sequential number uniquely identifying the logistics unit.
- **Digit 18 — Check Digit**: Calculated via the official **GS1 Modulo 10** algorithm.

### GS1 Modulo 10 Check Digit Algorithm (Reference Implementation)
```javascript
function calculateGS1CheckDigit(payload17) {
  const digits = String(payload17).replace(/\D/g, '').split('').reverse();
  let sum = 0;
  for (let i = 0; i < digits.length; i++) {
    sum += parseInt(digits[i], 10) * (i % 2 === 0 ? 3 : 1);
  }
  return (10 - (sum % 10)) % 10;
}
```

### Standard EDI Locations for SSCC
- **UN/EDIFACT (`DESADV` / `IFTMIN`)**:
  - `GIN+BJ+<SSCC>` (Goods Identity Number, qualifier `BJ` = Serial Shipping Container Code)
  - `RFF+SI:<SSCC>` or `RFF+AAK:<SSCC>`
  - `PAC` package segment
- **SAP IDoc (`DELVRY03` / `DELVRY07` / `DESADV01`)**:
  - Segment `E1EDL37` / `E1EDL44` → Field `<EXIDV>` or `<EXIDV2>` (External Handling Unit ID)
