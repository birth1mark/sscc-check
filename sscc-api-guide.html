03. Industrial Integration Manuals (Zebra TCP/IP & ERP)

Industrial Zebra thermal printers (ZT411, ZT231, GK420d, ZD421) listen on Raw TCP Port 9100 (JetDirect protocol). You can pipe the ZPL-II response from POST /v1/labels directly to your warehouse printer over the local network without drivers.

A. Direct Linux / Bash Dispatch to Zebra Printer (Port 9100)

# Generate Dual (1D GS1-128 + 2D QR Digital Link) ZPL and pipe directly to Zebra printer IP 192.168.1.200:9100
curl -s -X POST "https://sscc-labels.birth1mark.workers.dev/v1/labels" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sscc_pro_YOUR_KEY" \
  -d '{"gcp":"5601234","startSerial":1001,"quantity":5,"symbology":"dual","format":"zpl"}' \
  | nc -w 2 192.168.1.200 9100

B. Python / Odoo / Warehouse WMS Socket Integration

import socket, requests

def print_gs1_pallet_batch(api_key, zebra_ip, gcp, start_serial, qty, lot_no):
    res = requests.post(
        "https://sscc-labels.birth1mark.workers.dev/v1/labels",
        headers={"X-API-Key": api_key, "Content-Type": "application/json"},
        json={
            "gcp": gcp,
            "startSerial": start_serial,
            "quantity": qty,
            "symbology": "dual",
            "batchNo": lot_no,
            "format": "zpl"
        },
        timeout=5
    )
    res.raise_for_status()
    with socket.create_connection((zebra_ip, 9100), timeout=3) as printer:
        printer.sendall(res.text.encode("utf-8"))
    print(f"Dispatched {qty} GS1 labels to Zebra {zebra_ip}:9100")
